# DSE-By-Topic_Mensuration

HKDSE Mathematics（Compulsory Part）— **Mensuration 求積法** 3D 互動教學。

- **網頁 Web page**: <https://julietsztsz26-blip.github.io/DSE-By-Topic_Mensuration/>
- 單一 HTML 檔（`index.html`），毋須網絡連線即可使用。

## 內容

- Paper 1：17 題長題目（DSE 2012–2026，包括 DSE 2026 Q13）
- Paper 2：19 題 MC（DSE 2012–2026，包括 DSE 2026 Q16、Q17）
- 每題按小題逐步解說評分準則（M／A 分），並以可旋轉的 3D 模型同步動畫
- 每題設「本題總結 • Summary」：答案、分數分佈、解題路線、常見錯誤
- 左方「篩選」：按題號／按年份排列，可只看卷一／卷二 MC 或指定年份

根據 *DSE Assign J（Mensuration 2012–2026）Teacher Version* 製作。
